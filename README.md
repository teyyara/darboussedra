# Dar Boussedra — Digital Family Home

A local-first, intentionally unfurnished, navigable 3D family house. The first milestone focuses on architecture, room navigation, a data-driven room registry, and resilient accessible fallbacks. No backend, authentication, paid assets, analytics, or family-content storage is included.

The initial architecture is being added in AEOS Loop 001. See `AEOS_STATUS.md` and `evidence/research/` for the progression record and research dossier once the first implementation checkpoint is complete.
